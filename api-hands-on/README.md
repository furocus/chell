# cShell：コードを読んで補完する5日間ハンズオン

二重ポインタまで学習済みの5人が、「用途と使用意図」を理解するための教材です。VS Codeなどでコードとanswer.mdを並べ、TODOを補い、状態を手で追って解答・解説と照合します。ビルド・実行・環境構築は不要です。

**Aについて、一例を最初から最後まで読む場合は[起動用文字列と二重ポインタ（約120分）](A/READING.md)を使います。** 別課題やanswer.mdを参照せず、一文書で完結する読み物です。以下の5日間ハンズオンは既存教材として残しています。

## 配布内容

~~~text
README.md
A/  day1.c  day2.c  day3.c  day4.c  day5.c  answer.md
B/  day1.c  day2.c  day3.c  day4.c  day5.c  answer.md
C/  day1.c  day2.c  day3.c  day4.c  day5.c  answer.md
D/  day1.c  day2.c  day3.c  day4.c  day5.c  answer.md
E/  day1.c  day2.c  day3.c  day4.c  day5.c  answer.md
~~~

既存の5日間ハンズオンは、5フォルダー、課題C25本、answer.md5本、README.md1本の計31ファイルです。各日のコードには見本・2〜3か所のTODO・具体的な場面・問いをまとめています。このハンズオンに実行用main、補助ヘッダー、テスト、スクリプト、設定、exeは配布しません。これに加え、A/READING.mdを独立した読み物として用意しています。

| 担当 | 担当範囲 | 解答・解説 |
|---|---|---|
| A | 制御・外部実行 | [A/answer.md](A/answer.md) |
| B | 入力・表示 | [B/answer.md](B/answer.md) |
| C | 解析・所有権 | [C/answer.md](C/answer.md) |
| D | 現在位置・ディレクトリ | [D/answer.md](D/answer.md) |
| E | 基本コマンド | [E/answer.md](E/answer.md) |

## 1日の時間：上限120分

- **読解30分**：コード見本10分、コメントにある公式docsの指定節10分、answer.mdの概念説明10分。
- **実践90分**：TODO補完40分、場面の値・アドレス・所有権を手で追う25分、answer.mdの完成関数と照合15分、自分の言葉で説明10分。

解答の完成コードは折りたたんであります。先に補完し、その後で開いてください。早く終われば終了し、2時間になったら未解決をCファイル末尾へ1つ記して止めます。宿題や追加ファイルは求めません。

## 5日間で扱うこと

| 日 | 中心となる理解 | 本人の作業 |
|---|---|---|
| 1 | 成否と借用ポインタを分けて返す | 出力先の初期化と借用先を補完 |
| 2 | 確保した領域の所有権を渡す | 確保・コピー・所有権移動を補完 |
| 3 | 解放と呼び出し元の変数更新を分ける | free対象とNULL代入先を補完 |
| 4 | ポインタの表と二次元配列を区別する | 範囲内の要素を借りて返す |
| 5 | 実API・担当の境界で段数を判断する | 自分の担当に沿う1関数を補完 |

Day 1〜4の学習量は同じで、題材を担当の用途へ読み替えています。Day 5も小さな1関数だけに限定します。PATH探索・Ctrl+C同期・全文字列パーサ・列挙全体・環境保守を追加課題にしません。

## VS Codeでの進め方と完了判定

1. この教材フォルダーを開き、自分のdayN.cを開く。
2. 自分のanswer.mdを横へ開き、必要ならMarkdownプレビューを使う。
3. 見本を読んでから、指定した1関数のTODOだけを補う。
4. walkthroughの場面を実行せず、戻り値・変数・所有権を手で追う。
5. answer.mdの状態表と完成関数へ照らし、「なぜそのポインタの段数か」を説明する。

C/C++拡張は色分けなどに使えますが、インストールは必須ではありません。ヘッダーが見つからない等の赤線は環境による表示で、正誤判定には使いません。コードは読むための関数見本であり、exeとして起動する教材ではありません。

**完了条件は、補完した処理と状態表が一致し、借用／所有・変更対象・解放担当を説明できることです。** 式の書き方が解答例と違っても、契約が同じなら構いません。実機での動作確認済みという意味にはしません。

公式ドキュメントのURLと読む節は各Cファイル内に記載しています。説明はMicrosoft LearnのC／CRT／Win32仕様に沿い、教材独自の戻り値や失敗時の契約は各課題とanswer.mdで定義しています。ここでは有効な短い入力を扱い、巨大サイズ・並行処理・本体の全異常系は対象外です。

作業はローカルのみ。pushは行いません。
